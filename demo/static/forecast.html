Where the gap is heading if nothing changes

Every check produces a drift index — a single number for how much of the AI-fraud surface the current rulebook fails to catch. This page takes that number across past checks and projects where it goes next.

It is a planning aid, not a prediction of specific fraud. It answers “if we keep updating the rulebook at the pace we have been, how far behind will we be in six cycles?” — useful for arguing a review cadence, not for naming next quarter’s scam.

How the projection is calculated

Two modes, always labelled. With three or more recorded checks, the projection is fitted to your measured drift-index history. With fewer, it falls back to a clearly-marked baseline derived from the library scan — the page tells you which mode produced the line you are looking at.

The fit. A least-squares linear regression runs over the recorded drift-index series against time. That slope alone would be a poor forecast, so it is combined with a growth rate anchored in current measured evasion pressure (0.03 + 0.09 × AI-evasion share): the more of today’s evasions land on AI-relevant rules, the faster drift is assumed to compound.

Damping. Growth is compounded with a decay factor of 0.82 per step, so the curve saturates instead of running away. Unbounded exponential growth would be an artefact of the maths rather than a claim about the world, and the projection is clamped to the 0–100 range the index occupies.

The confidence band. Width comes from the residual error of the fit (RMSE), widening by 35% per step forward, with a minimum width so the band never implies more precision than there is. A wide band is the model telling you it does not know.

The backtest. A rolling-origin, one-step-ahead hold-out: the model is refitted using only data up to each point and asked to predict the next one it has not seen. Reported as mean absolute error, MAPE and bias — bias shows whether it systematically over- or under-shoots. Check these before trusting the line.

What it cannot do. It assumes the pattern in past checks continues. A structural change — a new typology class, a rulebook overhaul, a regulatory shift — breaks that assumption, and the model has no way of knowing it happened.
